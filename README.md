# neural_networks

Libretas de Jupyter en español para la materia de Redes Neuronales.

## Contenido

- `perceptron_basico.ipynb`: perceptrón simple aprendiendo las compuertas AND y OR.
- `perceptron_xor.ipynb`: por qué el perceptrón simple falla con XOR y cómo se resuelve con una red multicapa.

## Uso

Requiere Python 3.12+ y [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run jupyter lab
```
